# 📜 Classical Philosophy & Statecraft Text Explorer

A **RAG (Retrieval-Augmented Generation)** application to explore the
*Arthashastra* and *Bhagavad Gita* using natural language questions.

Built with **Python · LangChain · FAISS · OpenAI · Streamlit**.

---

## 🗂️ Project Structure

```
├── data/
│   └── arthashastra_and_gita_compendium_50p.pdf   ← source document
├── vector_store/
│   └── faiss_index/                                ← auto-generated by ingest.py
├── ingest.py        ← Run once: PDF → chunks → embeddings → FAISS index
├── rag.py           ← RAG engine: load index, retrieve, answer
├── app.py           ← Streamlit UI
├── .env             ← Your API keys (never commit this)
├── .env.example     ← Template for .env
└── requirements.txt ← Python dependencies
```

---

## ⚙️ Setup

### 1. Create a virtual environment (recommended)
```bash
python3 -m venv venv
source venv/bin/activate        # Mac / Linux
# venv\Scripts\activate         # Windows
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Set up your API key
```bash
cp .env.example .env
# Open .env and replace "your_openai_api_key_here" with your real key
```
Get your key from: https://platform.openai.com/api-keys

### 4. Run ingestion (ONE TIME ONLY)
```bash
python ingest.py
```
This loads the PDF, chunks it, generates embeddings, and saves a FAISS index
to `vector_store/faiss_index/`. **You never need to run this again** unless
the PDF changes.

### 5. Launch the app
```bash
streamlit run app.py
```
Open http://localhost:8501 in your browser.

## 🔄 How It Works

```
PDF ──► ingest.py ──► FAISS index (saved to disk)
                             │
User question ──► app.py ──► rag.py ──► retrieve top-4 chunks
                                           │
                                           ▼
                                      OpenAI LLM
                                           │
                                           ▼
                              answer + page references ──► Streamlit UI
```

| File | Runs | Purpose |
|---|---|---|
| `ingest.py` | Once | Build & save the vector index |
| `rag.py` | At app start | Load index, answer questions |
| `app.py` | Always | Streamlit UI |

---

## 🛡️ Design Principles

- **No hallucinations**: The LLM is instructed to answer only from the PDF.
  If the answer isn't there, it says so.
- **No repeated embeddings**: Embeddings are generated once in `ingest.py`
  and reused forever.
- **No hardcoded secrets**: All keys live in `.env`.
